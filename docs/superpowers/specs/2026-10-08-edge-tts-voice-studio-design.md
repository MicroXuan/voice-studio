# 声屿 Voice Studio：本地文本转语音网站设计

## 1. 项目目标

构建一个优先在个人电脑本地运行的中文文本转语音网站。用户可以粘贴几千字的中文文本，选择微软 Edge 在线语音角色，调整基础声音参数，查看生成状态，并在完成后试听或下载 MP3。

第一版服务单个本地用户，不包含账号、数据库或云端存储。代码需要保留以后部署为小规模公开免费服务的扩展空间，但不提前实现公开服务所需的限流、持久队列和身份系统。

## 2. 成功标准

- 安装 Python 依赖后，可用一条命令启动网页与 API。
- 能使用 `zh-CN-YunxiNeural`、`zh-CN-YunzeNeural` 和至少一个常用女声生成中文 MP3。
- 能稳定处理几千字文本，并在生成期间提供持续、可理解的进度反馈。
- 生成完成后可直接播放和下载音频。
- 空文本、非法参数、网络失败和微软语音服务异常均有明确的中文错误说明与恢复建议。
- 页面在 375px、768px、1024px 和 1440px 宽度下无横向滚动，支持键盘操作与减少动画设置。

## 3. 范围

### 第一版包含

- 长文本输入与实时字数统计
- 中文声音选择及角色说明
- 语速、音调、音量调节和恢复默认值
- 异步生成任务、生成进度和明确的加载状态
- MP3 在线播放与下载
- 临时文件自动清理
- 本地错误处理与基础自动化测试

### 第一版不包含

- 用户注册、登录或权限系统
- 历史记录与数据库
- SRT 或其他字幕导出
- 声音克隆、上传声音或自定义模型
- 云端对象存储
- 正式公共部署、计费或多实例任务协调
- 高级 SSML 编辑器

## 4. 技术架构

采用单体结构：FastAPI 同时提供 API 和静态前端，Python 服务直接调用 `edge-tts`。前端使用原生 HTML、CSS 和 JavaScript，不引入 Node.js 构建链。

主要模块：

- `app/main.py`：创建 FastAPI 应用、注册 API、托管静态资源，并负责应用启动与关闭时的生命周期操作。
- `app/tts_service.py`：封装 `edge-tts` 调用，将音频流写入 MP3，并通过回调报告进度。
- `app/job_store.py`：以内存结构保存任务状态，管理任务并发、错误结果和临时文件。
- `app/models.py`：集中定义请求参数、任务状态和响应模型。
- `static/index.html`：页面语义结构与表单。
- `static/styles.css`：设计令牌、响应式布局、交互状态及减少动画适配。
- `static/app.js`：表单状态、接口调用、任务轮询、播放器和错误反馈。
- `tests/`：参数校验、任务状态、接口行为与错误映射测试。

应用使用系统临时目录下的专属子目录保存 MP3。服务启动时清理过期文件，任务完成后按配置的保留时间清理。第一版同一时间只允许一个运行中的生成任务；新的重复提交返回可恢复的冲突提示。

## 5. API 设计

### `GET /api/voices`

返回第一版支持的精选中文声音，包括内部 voice ID、中文名称、性别和适用场景。声音清单由服务端维护，避免前端与后端参数不一致。

### `POST /api/jobs`

请求包含：

- `text`：去除首尾空白后必须非空，第一版最大 20,000 个 Unicode 字符。
- `voice`：必须属于服务端声音清单。
- `rate`：`-50%` 到 `+50%`。
- `pitch`：`-50Hz` 到 `+50Hz`。
- `volume`：`-50%` 到 `+50%`。

接口创建 UUID 任务，立即返回任务 ID 和初始状态。合成工作在后台任务中运行，不阻塞创建接口。

### `GET /api/jobs/{job_id}`

返回 `queued`、`running`、`completed` 或 `failed` 状态，以及 0–100 的进度、用户可理解的状态文字和可选错误信息。不存在或已清理的任务返回 404。

### `GET /api/jobs/{job_id}/audio`

仅完成的任务可访问。默认支持浏览器内播放；传入下载意图时使用安全、固定格式的文件名下载。未完成任务返回 409，失败或不存在的任务返回相应错误。

## 6. 合成与进度

`tts_service` 使用 `edge_tts.Communicate` 流式读取结果。音频数据块直接写入临时 MP3；遇到 WordBoundary 元数据时，根据已处理文本位置估算进度。由于边界事件与最终编码并非完全线性，运行阶段的进度最高显示为 95%，文件关闭并验证存在且非空后才更新为 100%。

几千字文本首先交由 `edge-tts` 自身的流式协议处理，不在第一版手工拼接多个 MP3。这样避免额外依赖 FFmpeg，也避免简单字节拼接带来的播放器兼容问题。若实测 20,000 字上限不能稳定工作，再在后续版本引入可验证的分段合成与音频封装方案。

## 7. 界面与视觉系统

产品名称为「声屿 Voice Studio」。页面是一张直接可工作的配音台，不使用营销首页结构。

### 视觉语言

- 背景 `#F4F7F9`：冷白录音纸面
- 前景 `#10233C`：墨蓝文字
- 主操作 `#1F6FEB`：电波蓝
- 状态强调 `#FF6B4A`：信号橙
- 表面 `#FFFFFF`：工作台卡片
- 边框 `#DCE6EF`：结构分隔
- 错误颜色使用满足对比度要求的深红语义色
- 中文正文采用本地优先的思源黑体/Noto Sans SC 字体栈；数字和参数采用 Space Grotesk 并提供系统字体回退

页面不依赖在线字体才能使用；无法加载网络字体时仍保持稳定布局。

### 布局

桌面端为左右工作台：左侧约三分之二用于长文本输入，右侧为声音与参数控制。生成结果区位于工作台下方，完成后显示稳定占位的播放器与下载操作，避免布局跳动。

手机端按文本、声音、参数、生成、播放的任务顺序排列为单列。所有可点击控件最小尺寸为 44×44px，正文基础字号不小于 16px。

### 标志性元素

页面顶部和生成状态区共享一条“声音指纹”波形。空闲时由文本长度决定疏密；生成时按真实任务进度点亮；播放时使用播放器时间驱动轻微位移。波形用于表达状态，不承担唯一的信息传达职责，旁边始终提供文字和百分比。

动画持续时间控制在 150–300ms，并尊重 `prefers-reduced-motion`。不使用装饰性大动画、玻璃拟态、AI 紫粉渐变或 emoji 图标；功能图标使用内联 SVG，并带可访问名称。

## 8. 交互状态

- 初始：显示示例提示、字数、默认声音和默认参数。
- 可生成：文本有效时主按钮启用。
- 生成中：表单关键项锁定，主按钮显示当前状态，进度同时用波形、进度条、百分比和文本表达。
- 完成：播放器、下载按钮和“重新生成”入口可用。
- 失败：错误出现在生成区域并通过 `aria-live` 宣告，同时提供“重试”操作；输入内容和参数保持不变。
- 参数重置：一键恢复语速、音调、音量为默认值，并提供即时视觉反馈。

页面避免仅靠颜色表达状态。焦点环仅在键盘导航时清晰显示，所有表单控件使用显式标签，不使用占位符代替标签。

## 9. 错误处理

服务端将底层异常映射为稳定的中文错误类型，不向浏览器泄露堆栈或内部路径：

- 网络连接失败：提示检查网络后重试。
- 微软语音服务拒绝或不可用：提示服务暂时不可用并稍后重试。
- 参数不合法：指出具体字段及允许范围。
- 已有任务运行：说明当前任务仍在生成，避免重复提交。
- 临时文件写入失败：提示检查本机磁盘空间或临时目录权限。

服务端日志保留异常详情供本地诊断，API 只返回用户可执行的恢复建议。

## 10. 测试与验收

自动化测试至少覆盖：

- 空文本、空白文本、超长文本与合法长文本
- 不存在的声音与越界参数
- 创建任务、状态转换、重复任务冲突和未知任务
- 未完成音频访问、已完成音频响应与过期文件
- `edge-tts` 网络异常和写文件异常的错误映射
- 使用模拟流验证进度不会倒退，完成前不达到 100%

人工验收至少覆盖：

- 使用云希、云泽和一个女声各生成一段中文音频
- 生成一篇几千字文本并完整播放生成文件
- 在 Chrome 或 Edge 检查播放与下载
- 在 375px、768px、1024px 和 1440px 宽度检查布局
- 仅使用键盘完成输入、选择、调参、生成、播放和下载
- 开启减少动画设置后确认不存在非必要动画
- 断开网络后确认错误文案明确且可重试

## 11. 后续公开部署扩展

从本地版本升级为每天几十位用户使用的公开免费服务时，保留现有前端和 API 语义，替换或补充以下基础设施：

- 在反向代理或应用层增加按 IP 的请求频率与每日字符额度限制
- 将内存任务存储替换为 Redis 等可过期任务存储
- 将后台任务移入单独工作进程，限制总并发
- 将音频转移到带生命周期规则的对象存储
- 增加请求大小、超时、磁盘配额、来源校验和服务监控

这些能力不进入第一版实现，也不在本地界面中制造无效设置。
